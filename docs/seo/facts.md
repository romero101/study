# База фактов для статей — по кластерам контент-плана

Собрано 19.09.2026 через поиск. **Все цифры — как их заявляет источник.** Кейсы агентств
и директологов — это их реклама: результаты выбраны лучшие, условия часто не раскрыты.
Использовать как ориентиры и примеры «в источнике X получили Y», всегда со ссылкой,
никогда как «средняя по рынку». Перед публикацией открыть источник и проверить контекст:
регион, год, бюджет, что считали заявкой.

Ролики для скачивания субтитров — `videos.csv` (56 штук, YouTube и Rutube), запуск локально:
`python3 seo/youtube_collect.py --from-csv seo/research/videos.csv`.

## Что показал сбор

1. **Кейсы есть почти по всем нишам, кроме септиков** — ниша без публичной фактуры, наш первый кейс будет один в выдаче.
2. **Разброс цены заявки внутри ниши — в 5–10 раз** (заборы 350–935 ₽, стройка 122–3 000 ₽). Это и есть главный тезис для статей: «средней цены нет, есть ваша, и она зависит от посадочной».
3. **Самые полные серии кейсов** — Михаил Попыванов на vc.ru (кровля, стройка, по годам), t4ka.ru, callibri.ru. На них можно ссылаться регулярно.
4. **Официальные ролики Яндекса про Директ** есть на YouTube — брать терминологию оттуда.
5. **Тема «накрутка отзывов на Картах»** в выдаче видео везде — статья 46 должна прямо от неё отстраиваться.
