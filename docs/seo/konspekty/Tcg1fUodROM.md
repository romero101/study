## О чём ролик
Первый ролик серии «как продвинуть сайт в 2026»: автор на странице своего агентства показывает, откуда собирать запросы для одной страницы, как расширить ядро и разбить его на группы по выдаче.

## Тезисы
- Семантика — процесс, с которого начинается продвижение: без позиций нет трафика, без трафика нет заявок.
- Первый источник — запросы, по которым страница уже показывается: Яндекс Вебмастер и Google Search Console с фильтром по странице за 3 месяца. Там много запросов без частоты в Вордстате, но они реальны.
- Второй источник — сервис анализа конкурентов: взять страницы из топ-10 и выгрузить запросы, по которым они видны.
- Третий — подсказки поиска и нейросети: попросить подобрать запросы по теме. У нейросети база знаний отстаёт от текущей даты, поэтому свежие материалы в неё ещё не попали.
- Частота на этапе сбора не главное; главное — почистить ядро от мусора и разбить на группы.
- Кластеризация — по совпадению выдачи: если по двум запросам в топе одни и те же страницы, это одна страница сайта. Проверять можно сравнением выдачи по двум запросам.
- Если по кластеру в топе стоят статьи, а не коммерческие страницы, — это информационный запрос, под него нужна статья.
- Если конкуренты делают отдельные страницы под подтемы, а выдача по ним своя, — нужна основная страница, подстраницы и ссылки между ними.
- Мусорные запросы в выгрузке Вебмастера бывают «накрученными» — их автор удаляет.
- Разбор своей страницы: только цены, выгоды, пара блоков, текст и вопросы — сегодня этого мало; по Метрике — единицы переходов из поиска и 66,7 % отказов, показы есть, кликов нет.
- Если сайта нет в первых сорока результатах по запросу, накрутка, по словам автора, не поможет — нужно работать со страницей.
- Текстовый анализ: если у конкурента из топа на странице нет важного запроса, а у вас он будет, его можно обойти.

## Что пригодится для статей
- 105 (семантика): источники запросов по порядку — Вебмастер своей страницы, конкуренты из топа, подсказки; кластеризация по совпадению выдачи; статья под информационный кластер.
- 106 (страницы под услуги): основная страница + подстраницы под подтемы, если выдача по ним своя.
- 107: «цены, выгоды, пара блоков и текст» уже не тянут страницу.
- 111: подстраницы связываются ссылками между собой.

## Оговорки
Автор продаёт SEO-услуги и промокод на платный сервис анализа конкурентов; пример — страница самого агентства («продвижение по трафику»), а не подрядчик. В ролике автор прямо говорит, что включал накрутку поведенческих на эту страницу, — это нарушение правил Яндекса, в статьи как рекомендация не переносить. Для небольшого сайта подрядчика ядро в сотни фраз на страницу избыточно. Расшифровка автоматическая, названия сервисов искажены.
