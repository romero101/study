## О чём ролик
Минутная инструкция от разработчика SEO-краулера: как массово получить данные о скорости и Core Web Vitals для любых сайтов через их программу, которая забирает показатели из Google PageSpeed Insights по API. Порогов и нормативов по метрикам в ролике нет — только порядок действий.

## Тезисы
- Проверку скорости и Core Web Vitals можно запустить для любого сайта, не только своего, — в десктопной программе-краулере компании (название в автоматической расшифровке искажено; судя по каналу, это Netpeak Spider — в ролике это прямо не проверить).
- Шаг 1: добавить в программу нужные сайты или их типовые страницы (не обязательно весь сайт — достаточно по одной странице каждого шаблона).
- Шаг 2: на боковой панели включить параметры из группы Google PageSpeed Insights.
- Шаг 3: автор советует дополнительно включить параметр «Время ответа сервера» из другой группы параметров.
- Шаг 4: нажать «Старт» и дождаться сбора данных.
- Время ответа сервера — время, за которое сервер ответил на запрос программы; чем меньше, тем лучше.
- Параметры PageSpeed Insights программа берёт напрямую из сервиса Google, поэтому в настройках нужно указать свой API-ключ; ключ бесплатный, ссылка на получение есть в окне настроек.
- Из сервиса можно получать разные типы данных: усреднённые по всему хосту и точечные по конкретному URL, с пометкой Field (данные реальных пользователей), отдельно для мобильных и для десктопа.
- У каждого параметра есть подробное описание в панели «Информация» внутри программы.
- После сбора результаты сортируются, группируются и фильтруются прямо в таблице — так собирается нужный отчёт.

## Что пригодится для статей
- Темы 63, 64 (как узнать скорость сайта и Core Web Vitals): способ проверить сразу много страниц или сайты конкурентов — краулер плюс API PageSpeed Insights, бесплатный API-ключ.
- Статьи про технический аудит сайта подрядчика: проверять не весь сайт, а типовые страницы каждого шаблона (главная, услуга, портфолио, статья).
- Статьи про скорость: разница между усреднёнными данными по хосту и полевыми данными по конкретному URL, отдельно мобильные и десктоп.
