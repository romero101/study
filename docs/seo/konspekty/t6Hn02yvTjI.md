## О чём ролик
Пошаговая инструкция по чистке работающей поисковой кампании: как открыть отчёт по поисковым запросам, найти в нём мусорные слова и добавить их в минус-слова. Показаны два способа — прямо в веб-интерфейсе для небольшой статистики и через выгрузку в Excel и генератор минус-слов для больших объёмов, а также добавление через Директ Коммандер.

## Тезисы
- Путь к отчёту: выбрать кампанию → общая статистика по кампании → вкладка «Поисковые запросы» → задать период.
- В фильтре под отчётом нужно убрать условие по кликам: смотреть надо не только запросы с кликами, но и те, где был только показ.
- Зачем смотреть запросы без кликов: среди них тоже есть мусор, такие показы портят общую статистику кампании и CTR.
- В отчёте видны сам запрос, ключевая фраза и тип условия показа, по которым система его подобрала; для чистки важен именно текст запроса.
- Способ 1, веб-интерфейс: отметить галочками запросы с неподходящими словами и нажать «Добавить в минус-фразы».
- В открывшемся окне можно оставить фразу целиком (если не хотите показываться именно по такому запросу) или стереть лишнее и оставить только мусорное слово.
- Уровень выбирается для каждой минус-фразы отдельно: одну — на всю кампанию, другую — только на группу объявлений; либо всё сразу на кампанию. Затем «Сохранить».
- Этот способ подходит, когда запросов за период немного — десятки или пара сотен.
- Способ 2, для большой статистики: кнопка «Экспорт», файл открывается в Excel в том же виде, что и в интерфейсе; столбец запросов копируется.
- Скопированные запросы вставляются в сторонний генератор минус-слов: сервис разбивает запросы на слова, по ненужным кликают мышью. Нажатое один раз слово подсвечивается во всех остальных запросах, повторно отмечать его не нужно.
- Примеры мусора из ролика: названия деталей и марок, которых нет в ассортименте рекламодателя.
- После прохода — «Получить список минус-слов», скопировать, открыть параметры кампании → «Редактировать» → «Минус-слова и минус-фразы», вставить, сохранить.
- Вариант через Директ Коммандер: сначала «Получить все данные» по кампании, чтобы подтянуть актуальное состояние с сервера; в параметрах кампании вставить минус-слова столбцом; сохранить и «Отправить все данные на сервер».

## Что пригодится для статей
- Тема 23 (минус-слова из поисковых запросов): готовая последовательность шагов для инструкции — где отчёт, какой фильтр снять, куда нажимать.
- Статьи про оптимизацию поисковых кампаний подрядчика: смотреть запросы без кликов, потому что они тянут вниз CTR.
