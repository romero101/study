## О чём ролик
Продолжение аудита 5EOlAbSRjxY: второй сайт того же заказчика — производителя рамп и эстакад из металла. Сайт «продуманнее» первого, разбор короче: вёрстка, первый экран, отзывы, контакты, опросный лист, семантика и схема кампаний.

## Тезисы
- На первом сайте рейтинг в виджете не совпадал с карточкой, потому что компания переехала и виджет тянул отзывы со старого адреса — виджет надо заменить.
- Страница второго сайта короче, поэтому до отзывов доходят чаще — это лучше.
- Вёрстка: значок гарантии выпал из блока, кнопка закрытия большого меню уезжает при прокрутке — должна быть закреплена.
- Если реклама идёт на всю Россию, регион доставки надо назвать на первом экране (в заголовке или подзаголовке); указание только Санкт-Петербурга вызывает вопрос, работают ли с другими регионами.
- Главные товары (рампы и эстакады) продвигаются с первого экрана — там же стоит показать минимальную цену, которая сейчас есть только ниже по странице.
- Ошибки в описаниях проектов недопустимы для «солидной компании с большими поставками».
- Виджет отзывов с хорошим рейтингом — на все страницы каталога, выше по странице, после каталога.
- Опросный лист лежит файлом на Google Диске — люди не любят такие ссылки; лучше собирать данные формой (например, Яндекс Формы). Калькулятор на сайте настроен нормально.
- По предварительной семантике можно собрать сильную кампанию: на хабовые страницы каталога — поисковая кампания, собранная вручную; на товары — товарная кампания Директа, которая ловит самые низкочастотные запросы и ведёт на релевантные карточки.

## Цифры
Цифр в ролике нет (кроме рейтинга 5,0 как цели, о котором см. оговорку).

## Что пригодится для статей
- «Сайт для металлоконструкций»: география на первом экране для B2B; цена «от» главного изделия на первом экране; опросный лист формой, а не файлом; аккуратность текстов проектов.
- «Где брать заказы на металлоконструкции»: схема Директа для производителя с каталогом — поиск на разделы, товарная кампания на изделия.
