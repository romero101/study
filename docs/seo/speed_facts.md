# Замеры скорости — что можно писать (исправлено 21.09.2026, вечер)

1. Секунды «главный экран за N с» (77,3 · 21,9 · 10,4 · 8,9 · 8,2 · 6,1 · 5,7 · 5,2 · 4,0) — Lighthouse из Амстердама на имитации медленного 4G. **Нигде не пишем.**
2. Вес по скрипту из Москвы (37 · 22,7 · 21 · 14,7 · 13 · 11 · 7,3 · 6,6 · 5,1 · 0,8 МБ) — тоже **неверен**: скрипт считал все файлы из кода страницы,
   включая то, что браузер при открытии не качает. **Заменить на таблицу ниже.**

**Правильный вес** — сколько байт скачивает браузер при открытии страницы (как «вес страницы» в PageSpeed; от места замера не зависит):

| Ниша, город | Вес их страницы | Вес нашей сборки той же страницы |
|---|---|---|
| Заборы, Нижний Новгород | 46 МБ | 0,3 МБ |
| Септики, Новосибирск (сайт на конструкторе) | 29,5 МБ | 0,3 МБ |
| Септики, Екатеринбург | 15 МБ | 0,2 МБ |
| Септики, Челябинск | 12,9 МБ | 0,1 МБ |
| Ремонт кровли, Санкт-Петербург | 7,8 МБ | 0,2 МБ |
| Бурение скважин, Екатеринбург | 5 МБ | 0,2 МБ |
| Бурение скважин, Санкт-Петербург | 4,2 МБ | 0,2 МБ |
| Заборы, Новосибирск | 2,1 МБ | 0,4 МБ |
| Строительство и отделка, Самара | 1,8 МБ | 0,4 МБ |
| Строительство и отделка, Санкт-Петербург | 1,7 МБ | 0,4 МБ |

Последние три — **не тяжёлые**, как пример тяжёлого сайта их не использовать (Санкт-Петербургская отделка раньше шла как «22,7 МБ» — это была ошибка).
Диапазон по десяти сайтам: 1,7–46 МБ; наши сборки 0,1–0,4 МБ.

Медленный ответ сервера **из Москвы** (до начала загрузки страницы): септики, Челябинск — 2,8–3,6 с; ремонт кровли, СПб — 1,1–1,5 с.

Как подавать:
- «Страница весит 46 МБ — больше сотни обычных лендингов. На мобильном интернете за городом она открывается долго; на офисном Wi-Fi вы этого не заметите — проверьте с телефона».
- Сколько именно секунд на мобильном — не пишем.
- Сноска: «Вес страницы — сколько скачивает браузер при открытии, сентябрь 2026. «Было» — действующий сайт компании, «стало» — наша сборка той же страницы с теми же фото и текстами».
