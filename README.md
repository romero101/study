# Форма сайта — производство лендингов для подрядчиков

Репозиторий студии: генератор лендингов, готовые площадки и мини-CRM
для ведения сделок.

## Что внутри

```
builder/            генератор: один шаблон -> много площадок
  css.py            критический CSS (встраивается в <head>)
  js.py             весь клиентский JS (~8 КБ, без библиотек)
  render.py         сборка HTML из данных площадки
  sites.py          контент площадок   <- сюда добавляется новый клиент
  placeholders.py   заглушки под фото, чтобы демо не выглядело пустым
  shared/           файлы, одинаковые для всех: send.php, .htaccess, policy.html
dist/<slug>/        готово к заливке на хостинг
```

## Сборка

```bash
python3 builder/build.py          # собрать все площадки в dist/
python3 builder/placeholders.py   # перерисовать заглушки под фото
```

Новая площадка: скопировать словарь в `builder/sites.py`, поменять контент,
добавить в `ALL`, собрать. Разработка одного лендинга — замена текстов, а не вёрстки.

## Заливка на хостинг (REG.RU)

1. Панель управления -> Файловый менеджер -> каталог поддомена
   (`/www/<поддомен>.formasaita.ru/`).
2. Загрузить **содержимое** `dist/<slug>/` — файлы, не саму папку.
3. Реальные фото положить в `img/` поверх заглушек, имена не менять
   (список — в `img/ПОЛОЖИТЬ-СЮДА-ФОТО.txt`).
4. В `send.php` вписать почту и, желательно, токен Telegram-бота —
   тогда заявки приходят на телефон за секунды.
5. Проверить: открыть сайт, посчитать в калькуляторе, отправить тестовую
   заявку, убедиться что она пришла.

## Перед показом клиенту

Поиск по слову `СОГЛАСОВАТЬ` в `builder/sites.py` — это всё, что придумано
за клиента и требует подтверждения: тарифы, гарантии, адреса, реквизиты.

## Перед запуском на боевом домене

- убрать демо-плашку (одна строка в `builder/render.py`, помечена комментарием);
- в `sites.py` поставить `"demo": False` — снимется `noindex`;
- заменить заглушки на реальные фото;
- вписать номер счётчика Яндекс.Метрики в `"ym"`;
- заполнить реквизиты в `policy.html`.

## Мини-CRM

`dist/formasaita/admin/` — ведение сделок по воронке: было/стало, этап,
комментарии. Подробности в `dist/formasaita/admin/README.md`.
