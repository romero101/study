# Фактура для нишевых страниц «Сайт для <ниша>»

Страница продаёт услугу студии «Форма сайта» (сайты для подрядчиков) владельцу компании из ниши.
Читатель — подрядчик, не маркетолог. Главная мысль студии: он уже платит за рекламу, а сайт теряет оплаченные клики.

На каждую нишу — один файл `content/niches/<slug>.json` (UTF-8, валидный JSON, без комментариев) со строго такими полями:

{
  "slug": "zabory",
  "name": "заборы",                       // как в запросе: «сайт для …» → поле "for"
  "for": "заборов",                        // родительный: «Сайт для заборов»
  "who": "компании, которые ставят заборы и ворота",   // кто клиент студии
  "client": "владелец дома или дачи",      // кто ЕГО клиент
  "h1": "Сайт для заборов, <span>который считает цену за метр.</span>",   // до 70 знаков, вторая часть в <span>
  "intro": "2–3 предложения: как выбирает клиент этой ниши и что должен делать сайт.",
  "search": ["забор из профнастила цена за метр", "забор под ключ", "откатные ворота цена"],  // 4–6 реальных по смыслу запросов клиентов ниши, без выдуманных частот
  "pains": [["Заголовок боли", "2–3 предложения: что именно идёт не так на сайтах этой ниши и чем это оборачивается"], … ровно 6],
  "calc": {"type": "по метражу|по глубине|по ступеням|по смете|квиз", "params": ["длина", "тип", "высота", "ворота"], "why": "1–2 предложения, почему именно так считать в этой нише; если точную цену назвать нельзя — сказать честно и предложить вилку или квиз"},
  "blocks": [["Блок сайта", "что в нём должно быть именно для этой ниши"], … ровно 6],   // первый экран, расчёт, объекты, отзывы, гарантии/договор, заявка — с нишевой спецификой
  "photos": "что снимать на объектах в этой нише, 1–2 предложения",
  "season": "когда спрос, когда спад и что делать с рекламой, 1–2 предложения, без цифр",
  "direct": "особенности рекламы в Директе в этой нише: какие запросы пустые (перечисли 5–8 минус-слов в тексте), что с географией, 2–3 предложения",
  "faq": [["Вопрос владельца из этой ниши", "Ответ, 2–4 предложения"], … ровно 5],
  "placeholder": "Например: ставим заборы в Самаре, реклама идёт, заявок мало"
}

Правила:
- Никаких выдуманных цифр, процентов, «по статистике», средних чеков и цен работ в нише. Цены студии упоминать можно только такие:
  лендинг 60 000 ₽, сайт компании от 110 000 ₽, калькулятор или квиз от 15 000 ₽, посадочная под услугу или город 18 000 ₽,
  настройка Директа 15 000 ₽, ведение 15 000 ₽/мес, демо и аудит бесплатно.
- Никаких названий компаний. Мессенджеры — MAX и Telegram, WhatsApp не упоминать.
- Не обещать результат («заявок станет втрое больше»). Обещаем измеримое: секунды загрузки, цену заявки до и после.
- Каждая ниша — своя фактура: свои боли, свои параметры расчёта, свои вопросы. Нельзя копировать формулировки между нишами —
  поисковик склеит одинаковые страницы. Пиши как человек, который знает, как в этой нише покупают.
- Текст простой, без канцелярита и восклицательных знаков. Ёлочки «», тире —.
- В HTML допустим только <span> в h1. Кавычки внутри строк JSON — «ёлочки», не ".
- В конце проверь: `python3 -c "import json,sys;[json.load(open(f)) for f in sys.argv[1:]]" content/niches/<твои файлы>`.
