# Передача работы в локальную сессию

Файл для Claude Code, запущенного локально. Прочитай целиком перед первым действием.

## Заказчик и контекст

Студия «Форма сайта» (formasaita.ru) продаёт лендинги подрядчикам: бурение скважин,
заборы, септики, кровля. Схема продаж: сначала собрать демо клиенту, потом звонить
и показывать готовое. Хостинг REG.RU, поддомены `<slug>.formasaita.ru`.
Менеджер продаж — Неделькин, для него сделана админка.

## Что уже есть в репозитории

- `builder/` — генератор лендингов (python3, без зависимостей): один шаблон, контент
  площадки в `sites.py`. Сборка: `python3 builder/build.py` → `dist/<slug>/`.
- `dist/topdrillrus/`, `dist/skvazhina-ekb/` — МОЯ пересборка двух демо с нуля.
  **Заказчику она не нужна** — см. ниже. Не развивать без его команды.
- `dist/formasaita/admin/` — мини-CRM на PHP: 10 сделок перенесены из Excel
  (`builder/data/forma-saita-sales.xls`, скрипт `builder/crm_seed.py`), воронка
  Не связывались → Дозвонился до ЛПР → Отправил лендинг → Взял обратную связь →
  Счёт выставлен → Оплачено → Отказ, карточка «было/стало», комментарии.
  Логин `админ` / пароль `admin` — заказчик попросил именно так; в интерфейсе висит
  предупреждение сменить. Проверено в браузере, работает.
- `README.md` — как собирать и заливать на REG.RU.

## Главное: чего хочет заказчик прямо сейчас

Взять **исходный** лендинг ТопДриллРус, который уже лежит на хостинге по адресу
`https://topdrillrus.formasaita.ru/` (сделан в предыдущей сессии, файлы в
`/www/topdrillrus.formasaita.ru/` на REG.RU), и **точечно допилить**:
мобильную вёрстку, конверсию, скорость, лидген. НЕ переписывать заново.
Заказчику нравится тот вариант; в нём есть настоящие фото объектов и отзывы
с источником — их сохранить.

Предыдущая облачная сессия этого сделать не смогла: исходящая сеть была закрыта
(403 на formasaita.ru, topdrill.spb.ru, reg.ru), браузера не было. Поэтому она
пересобрала сайты с нуля — заказчик это отверг: «плохая мобильная вёрстка,
ни одной фотографии, исчезли отзывы». Претензии справедливы: фото были недоступны
(стоят серые заглушки), отзывы не выдумывались намеренно.

## Первые шаги локально

1. Открыть `https://topdrillrus.formasaita.ru/` в браузере, посмотреть на телефонной
   ширине (390px) — найти, что «едет». Спросить заказчика, если неочевидно.
2. Скачать исходные файлы с хостинга (или попросить заказчика) в
   `dist/topdrillrus-original/` — работать с ними, а не с `dist/topdrillrus/`.
3. Из моей пересборки можно переносить точечно, если заказчик одобрит:
   `builder/shared/send.php` (заявки в Telegram + почта + журнал, антиспам, дубли),
   `builder/shared/.htaccess` (сжатие, кэш, https), закреплённую панель
   «Позвонить / WhatsApp» на мобильном, ленивую загрузку Метрики.
4. Залить результат обратно в `/www/topdrillrus.formasaita.ru/` через файловый
   менеджер REG.RU или FTP.
